# 「기록의 주인」 제작기

초등 5~6학년 한국사 수업용 기록 복원형 탐구 게임. 이 문서는 실제 구현된 내용만을 근거로 기획 의도와 구조를 정리한다.

## 왜 만들었나

독립운동가 학습은 업적 목록 암기로 흐르기 쉽다. 이 게임은 질문을 뒤집는다 — "이 인물이 무엇을 했나"가 아니라 **"이름이 지워진 이 기록의 주인은 누구인가"**. 학생은 문서·사진·물건을 직접 찾고, 겹쳐 보고, 연표에 놓고, 관계를 이어서 근거로 인물을 밝혀낸다. 정답 맞히기 퀴즈가 아니라 근거 수집 → 판단의 탐구 과정을 게임 구조 자체로 만든 것이다.

- 성취기준: [6사06-01] 일제 식민 통치와 저항, [6국02-03] 자료의 타당성 평가, [6국01-03] 질문하며 듣고 말하기.
- 다루는 인물: 윤봉길·김구·유관순·안중근·안창호 5인. 사건(선택 상자) 하나마다 인물 트랙 하나.

## 게임 흐름

```
사건 선택 → 흔적 탐색(기록실에서 단서 찾기, 탭·서랍·뒤집기·문지르기 등 조작)
→ 자료 분석(두 기록 겹쳐 보기 · 연표 배치 · 관계 선 잇기)
→ 기록 탐구(조사권 3회로 질문 5개 중 선택, 기록 원문에 밑줄 긋기)
→ 기록 복원(시간 순서 + 인물·시기·조직·활동·역할 슬롯 채우기)
→ 인물 파일 해금 + 역사 기록관 인증서 출력
```

설계 원칙: 랜덤 클릭으로 못 풀게 한다. 단서가 아닌 물건이 반드시 섞여 있고, 이어지지 않는 관계 카드가 반드시 있고, 조사권은 질문 수보다 적다. 이 규칙들은 `scripts/validate-history.mjs`가 데이터 전체에 강제한다.

## 구조

- **Vite + TypeScript + Phaser.** Phaser는 공간·조작·연출만, DOM/CSS는 텍스트·버튼·모달·인증서만 맡고 둘은 EventBus로만 통신한다. 텍스트를 이미지에 굽지 않아 오타 수정·역사 검수 반영·접근성이 모두 텍스트 편집으로 끝난다.
- **데이터 주도.** 인물별 하드코딩 없이 `public/data/cases/case-00N/track-*.json` 하나로 트랙 하나가 성립한다. Scene 코드는 전 트랙이 재사용한다.
- **출처 강제.** 화면에 나가는 모든 역사 정보는 `historical-sources.json`의 claim을 근거로 하고, `status: "approved"`가 아니면 노출되지 않는다. 출처는 공훈전자사료관·독립기념관·민족문화대백과·우리역사넷·국가유산청으로 한정.

## 교육적 안전장치

- 독립운동가에게 수사 용어(용의자·범인·심문·검거·혐의)를 쓰지 않는다. 검증 스크립트가 데이터 전체에서 차단한다.
- 오답 피드백은 "틀렸습니다" 금지. 무엇을 다시 확인할지 알려 주는 문장으로만 쓴다(이것도 스크립트가 검사).
- 생성형 AI로 만든 인물 그림은 "학습용 시각화"로 명시하고 초상 사진처럼 제시하지 않는다.
- 학생 개인정보(이름·학년·반·번호)는 입력받지도 저장하지도 않는다. 인증서는 빈칸으로 인쇄해 손으로 쓴다.
- 연표에 적는 연도는 지어낼 수 없다 — approved claim의 날짜와 대조해 스크립트가 검증한다.

## 교실 운용

로컬 저장(localStorage)으로 이어하기가 되고, PWA(sw.js + manifest)로 오프라인에서도 돌아간다. 폰트는 셀프호스팅이라 외부 CDN 요청이 없다.
