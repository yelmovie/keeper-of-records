# 「기록의 주인」 기능 향상기 (2026-08)

초기 공개 이후 진행한 개선 작업 기록. 실제로 적용된 변경만 적는다.

## 1. 소셜 공유(OG) 정비

- OG 이미지를 새로 만들어 교체하고(`public/og.jpg`, 1200×600), `og:title`·`og:description`·`og:url`·`twitter:card(summary_large_image)` 메타태그를 정비했다. 링크를 공유하면 제목·설명·이미지가 제대로 뜬다.

## 2. PWA / 오프라인

- 서비스워커(`public/sw.js`)와 `manifest.webmanifest`를 갖춰 설치형으로 쓸 수 있고, 프로덕션 빌드에서 자동 등록된다(`src/main.ts`). 학교망이 불안해도 캐시로 진행이 이어진다.

## 3. 타이포그래피 상향

- 제목·버튼용 Jua, 본문용 Pretendard를 셀프호스팅/번들로 제공(외부 폰트 요청 0). 디자인 토큰(`src/ui/styles/tokens.css`)으로 글꼴·크기를 일원화했다.

## 4. 역사 사실 검수 반영

사용자(교사) 검수로 확정된 사실 수정:

- **유관순 순국 나이**: "열여덟 살" → 만 나이 기준 **"열일곱 살"**로 전 데이터 통일 (claim·트랙·인물 프로필).
- **안중근 단지동맹**: "동지 열두 명과 함께" → **"동지 열한 명과 함께"**(본인 포함 12인)로 수정.
- **윤봉길 선서문 소장처**: 국립중앙박물관 소장(보물 568-1호)으로 확인 — 수정 없이 유지.

## 5. 김좌진 콘텐츠 제거

- 김좌진 트랙(track-kimjwajin.json)과 관련 데이터(claim 8건, 인물 항목, 북로군정서·호명학교·신민부 조직 항목), 이미지 에셋 13개를 제거했다. 파일은 삭제하지 않고 `_unused/`로 이동(목록: `_unused/DELETE-CANDIDATES.md`).
- 남은 트랙의 오답 선택지에 있는 "북로군정서"·"청산리 전투"는 특정 인물 서술 없이 일반 역사 지식 수준이라 유지했다.
- 게임은 인물 5인(윤봉길·김구·유관순·안중근·안창호) 체제로 정리됐다.

## 6. 데이터 정리

- 어느 코드에서도 쓰지 않는 인물 비교(compare) 스테이지 잔존 데이터를 트랙 JSON과 스키마에서 제거했다.
- 안창호 트랙(5번째 사건)의 탐색 필수 근거를 3개→4개로 올려 후반 난이도를 상향했다.
- v2로 대체된 구버전 이미지 12개를 `_unused/assets/`로 이동해 배포 용량을 줄였다.
- 에셋 출처·라이선스를 `assets/CREDITS.md`로 정리했다(폰트 OFL, 생성형 AI 이미지 고지, WebAudio 합성 효과음, BGM 출처 확인 필요 표시).
